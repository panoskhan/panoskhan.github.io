How to use the Base64 Encoder & Decoder

When to use it

Use this tool when you need to encode text for a data URL, an email header or an API field, or to read a Base64 string you have received.

Step by step

  1. Paste the text or Base64 string.
  2. Choose Encode or Decode.
  3. Convert it.
  4. Copy the result and check the size comparison.

Example

The text "hello" encodes to aGVsbG8=, and decoding it returns the original text.

Good to know

Base64 is an encoding, not encryption. Anyone can decode it, so never use it to protect sensitive information.
