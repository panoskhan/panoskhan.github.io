# Contributing

Thank you for helping improve Entity Readiness Audit.

## Good contributions

- Add a clearly defined public HTML signal that can be checked locally.
- Improve accessibility or browser compatibility.
- Add documentation and examples.
- Improve error handling without overstating what a result means.
- Keep the tool privacy-preserving and credential-free.

## Avoid

- Claims that a check guarantees search rankings, indexing, Knowledge Panels, or Wikidata eligibility.
- Collection of passwords, API keys, or private account data.
- Automated spam submissions or backlink generation.
- Checks that require a proprietary search-engine API without clearly documenting the dependency.

Please explain the reason for a new check and provide a reproducible example where possible.
