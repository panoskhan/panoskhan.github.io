Design principles

Search visibility

Keep important public text and metadata crawlable.

Privacy boundary

Never place credentials, private conversations or proprietary secrets in frontend code.

Public usability

The visitor should experience a complete product without needing repository access.

Reversible architecture

Start with the static public prototype and add a backend when real server-side processing is needed.
