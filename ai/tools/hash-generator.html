How to use the Hash Generator

When to use it

Use this generator to create a checksum of text, compare whether two values are identical, or learn how hashing works.

Step by step

  1. Enter the text.
  2. Choose SHA-256, SHA-384, SHA-512 or SHA-1.
  3. Generate the hash.
  4. Compare it with the expected value character by character or by copy and paste.

Example

Hashing the same sentence twice always produces the same SHA-256 value, while changing a single letter produces a completely different one.

Good to know

Plain fast hashes are not suitable for storing passwords. Password storage needs a slow algorithm designed for it, such as bcrypt or Argon2.
