How to use the JWT Decoder

When to use it

Use this decoder when debugging login or API problems and you need to see what a JSON Web Token contains and when it expires.

Step by step

  1. Paste the token that starts with eyJ.
  2. Decode it.
  3. Read the header and payload.
  4. Check the exp and iat claims to see expiry and issue time.

Example

A developer finds that API calls fail because the token's exp claim shows it expired ten minutes earlier.

Good to know

Decoding is not verification. Only the server holding the key can confirm a token is genuine, and production tokens should not be pasted into online tools.
