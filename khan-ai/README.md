# KHAN AI — Foundation

KHAN AI is an iPhone-first, modular AI-agent platform. The assistant identity is **KHAN**.

## Product principles

- Model-agnostic AI router: models are replaceable behind stable interfaces.
- Agent Core: understand → plan → use tools → verify → respond → remember.
- Memory: short-term task context plus explicit long-term memories.
- Tools: web research, files, projects, calendar/reminders, and future integrations.
- Guard: permission tiers and confirmation for consequential actions.
- Voice and Vision as first-class interfaces.
- Apple integration through App Intents, Siri, Shortcuts, Spotlight, widgets, and supported system surfaces.
- Galaxy ecosystem UI: planets represent capabilities; the central black hole represents KHAN Core.

## Current repository scope

This directory is intentionally isolated from the existing Panos Khan public website. It is the product foundation/prototype area until a dedicated KHAN AI application repository is created.

## Visual system

- Near-black space background.
- Central black-hole core with accretion-disk glow.
- Orbital rings with depth and parallax.
- Distinct planet colors per capability.
- Subtle stars/nebulae; no flat dashboard-card aesthetic.
- Mobile-first layout with touch-friendly targets.
- Motion should respect `prefers-reduced-motion`.

## Capability planets

Research · Knowledge · Projects · Automation · Creativity · Communication · Strategy · Tools

The list is extensible. Planet position is data-driven so the same ecosystem can scale from iPhone to larger displays.
