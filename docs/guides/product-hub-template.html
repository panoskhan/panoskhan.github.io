Adding a product hub

Use this checklist so new products feel native to the ecosystem without duplicating shell code or redesigning the homepage.

  1. Create folder: /product-name/index.html using /templates/product-hub.html.
  2. Register product: add an entry to /assets/data/products.json.
  3. Search: add catalog entries to /assets/data/search-index.json.
  4. Shell: include data-site-nav, data-site-footer, and /assets/js/site.js.
  5. SEO: title, description, canonical, Open Graph, Twitter Card, JSON-LD + breadcrumb schema.
  6. A11y: one h1, landmarks, focusable controls, meaningful link text.
  7. IA links: related products module, sitemap entry, validation list update.
  8. Quality: run python3 scripts/validate_static.py and spot-check keyboard navigation.

Validation

Critical pages are listed in scripts/validate_static.py. New public hubs must be added there and to sitemap.xml.
