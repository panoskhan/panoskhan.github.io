## Code Review Checklist

**Every PR must be reviewed for:**

### 1. Architecture Compliance

- ✅ Follows existing folder structure
- ✅ Uses shared design system (no duplicate CSS)
- ✅ Uses existing components (no new patterns)
- ✅ No unnecessary code duplication
- ✅ Extends existing patterns, doesn't override

**Questions to ask:**
- Could this reuse an existing component?
- Is this CSS duplicated elsewhere?
- Does this follow the folder structure?
- Is this the simplest solution?

### 2. Accessibility

- ✅ One `<h1>` per page (if added)
- ✅ Heading hierarchy doesn't skip levels
- ✅ Keyboard navigation works
- ✅ Focus is visible on all interactive elements
- ✅ Form labels are associated with inputs
- ✅ Images have alt text (or empty if decorative)
- ✅ Color contrast 4.5:1 minimum
- ✅ ARIA used correctly (if present)
- ✅ axe DevTools scan shows 0 violations

**Test:** Tab through page, press Enter on buttons, test with screen reader

### 3. Performance

- ✅ No new render-blocking resources
- ✅ Images are optimized (< 500KB each)
- ✅ No new unminified CSS/JS
- ✅ CSS/JS defer non-critical resources
- ✅ No performance regression (compare Lighthouse)
- ✅ No new web fonts (system stack only)

**Test:** Run Lighthouse, check for regressions

### 4. SEO

- ✅ Page has title tag (new pages)
- ✅ Page has meta description (new pages)
- ✅ Page has canonical URL (new pages)
- ✅ Page has JSON-LD schema (new pages)
- ✅ Breadcrumb navigation present
- ✅ Internal links are descriptive (not "click here")
- ✅ No duplicate titles/descriptions

**Test:** Check source code for meta tags, run SEO audit

### 5. Code Quality

- ✅ No console errors or warnings
- ✅ No unused code or CSS
- ✅ Clear, self-documenting code
- ✅ Comments explain "why," not "what"
- ✅ Consistent with existing style
- ✅ Semantic HTML used
- ✅ No inline CSS or JavaScript (except necessary)

**Questions to ask:**
- Is this code easy to understand?
- Would someone else maintain this easily?
- Is there unnecessary complexity?
- Are comments helpful?

### 6. Testing Coverage

- ✅ Tested on desktop (Chrome, Firefox, Safari, Edge)
- ✅ Tested on mobile (iOS Safari, Chrome Android)
- ✅ Keyboard navigation tested
- ✅ Screen reader tested (VoiceOver or NVDA)
- ✅ No JavaScript errors (F12 > Console)
- ✅ Links are not broken (internal + external spot check)

### 7. Commit Messages

- ✅ Clear, descriptive title (50 chars max)
- ✅ Proper format: `<type>: <scope> – <description>`
- ✅ No "AI created this" or placeholder messages
- ✅ Focuses on "why," not just "what"

**Examples:**
```
✅ feat: add AI Platform product guide
✅ perf: optimize hero image loading
✅ a11y: improve button contrast and focus states
✅ fix: correct breadcrumb navigation on device pages

❌ Update files
❌ Generated by AI
❌ Various fixes
```

## Automated Testing

### Lighthouse Audit

**Online Tool:**
1. Go to https://pagespeed.web.dev/
2. Enter URL
3. Click "Analyze"
4. Review all 4 metrics (Performance, Accessibility, Best Practices, SEO)
5. Target: 95+ on all

**Command Line:**
```bash
# Install
npm install -g lighthouse

# Run audit
lighthouse https://panoskhan.github.io/page/ --output=json > report.json

# Check scores in report
cat report.json | grep score
```

### axe Accessibility Scan

**Chrome Extension (axe DevTools):**
1. Install from Chrome Web Store
2. Open DevTools (F12)
3. Click "axe DevTools" tab
4. Click "Scan ALL of my page"
5. Target: 0 violations

**Command Line (Node.js):**
```bash
# Install
npm install -g @axe-core/cli

# Run scan
axe https://panoskhan.github.io/page/ --output json > axe-report.json

# Review results (should be empty violations array)
```

### Link Validation

**Check all internal links work:**
```bash
# Manual spot-check critical paths:
# 1. Homepage → all product pages
# 2. Product pages → related content
# 3. Footer links → all destinations

# Or use script (if available)
# python scripts/validate_static.py
```

## Manual Testing

### Desktop Testing

**Browsers:**
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

**Checklist:**
- [ ] Page loads without errors (F12 > Console)
- [ ] All images display correctly
- [ ] Links work (try 5-10 links)
- [ ] Navigation works
- [ ] Forms work (if applicable)
- [ ] No layout issues
- [ ] Colors look correct

### Mobile Testing

**Devices:**
- iPhone 12+ (iOS Safari)
- Android phone (Chrome Mobile)
- Tablet (iPad or Android tablet)

**Checklist:**
- [ ] Responsive layout (no horizontal scroll)
- [ ] Touch targets are large enough (44px min)
- [ ] Text is readable without zooming
- [ ] Images load correctly
- [ ] Navigation drawer works (if applicable)
- [ ] Forms are usable (keyboards appear)

### Keyboard Navigation Testing

**Steps:**
1. Unplug mouse or disable trackpad
2. Press `Tab` to move forward
3. Press `Shift+Tab` to move backward
4. Press `Enter` to activate
5. Press `Escape` to close modals
6. Verify focus is always visible
7. Verify tab order is logical (left-to-right, top-to-bottom)

### Screen Reader Testing

**Windows (NVDA):**
1. Download https://www.nvaccess.org/
2. Install and start NVDA
3. Open page in browser
4. Arrow keys read content
5. Check: page title, headings, links, forms

**Mac (VoiceOver - built-in):**
1. `Cmd+F5` to enable
2. `VO` (Caps Lock or Ctrl+Opt) + arrow keys to navigate
3. Check: page title, headings, links, forms

**Test for:**
- [ ] Page title is announced
- [ ] Heading hierarchy is clear
- [ ] Links are descriptive
- [ ] Form labels are read
- [ ] Images have alt text

## Performance Verification

### Lighthouse Scores

**Target:** 95+ on all metrics

| Metric | Target | What to Check |
|--------|--------|---------------|
| **Performance** | 95+ | LCP, FID, CLS, load time |
| **Accessibility** | 95+ | WCAG AA compliance |
| **Best Practices** | 95+ | Security, browser standards |
| **SEO** | 95+ | Meta tags, structured data |

**If score is below 95:**
1. Click on failed item
2. Read recommendation
3. Fix issue
4. Re-run Lighthouse
5. Verify score increased

### Core Web Vitals

**Target:**
- **LCP:** < 2.5s
- **FID:** < 100ms
- **CLS:** < 0.1

**Test with:**
- Chrome DevTools > Lighthouse
- PageSpeed Insights
- Web Vitals Chrome Extension

### Asset Size Verification

**Check file sizes:**
```bash
# CSS total < 50KB
ls -lh /assets/css/*.css

# JS total < 100KB
ls -lh /assets/js/*.js

# Images < 500KB each
ls -lh /assets/images/*
```

## SEO Verification

### Meta Tags Check

**For each page, verify:**
- [ ] `<title>` (50-60 chars, unique)
- [ ] `<meta name="description">` (150-160 chars, unique)
- [ ] `<link rel="canonical">` (absolute URL)
- [ ] Open Graph tags (og:title, og:description, og:url, og:image)
- [ ] Twitter Card tags (twitter:card, twitter:title, twitter:image)
- [ ] JSON-LD schema (appropriate type for page)

**Test with:**
- Open page in browser
- Right-click > View Source
- Search for `<meta name="description"`
- Check all meta tags are present

### Structured Data Verification

**For new pages:**
1. Add JSON-LD schema appropriate to page type
2. Validate at https://validator.schema.org/
3. Check that all fields are populated
4. Ensure no errors in validator

### Internal Linking Check

**For each new page:**
- [ ] Linked from product index
- [ ] Linked from breadcrumb navigation
- [ ] Links to related content
- [ ] Links to other products (if applicable)
- [ ] Footer link if top-level page

**Test:**
1. Click every internal link
2. Verify destination is correct
3. Spot-check 5-10 external links

## Link Validation

### Internal Links

**Spot-check process:**
1. Open homepage
2. Click each product link → verify page loads
3. On each product page → click 3-5 internal links → verify work
4. Test breadcrumb navigation
5. Test footer links

**Common issues:**
- Broken path (e.g., `/ai-platform/` instead of `/ai/`)
- Typo in filename
- Moved file without redirect
- Removed file still linked

### External Links

**Spot-check process:**
1. Randomly select 10 external links
2. Click each one
3. Verify destination is still valid
4. Report dead links

**Tools:**
- Manual: Spot-check as above
- Automated (future): Use LinkChecker or similar

## Common QA Issues

### Issue: High Bounce Rate on New Page

**Possible Causes:**
1. Title/description don't match content
2. Slow page load
3. Poor mobile experience
4. Content quality low

**Fix:**
1. Check Search Console (is it indexed?)
2. Review Lighthouse score
3. Test mobile (responsive? readable?)
4. Review page content (does it answer user intent?)

### Issue: Page Not Indexed in Google

**Possible Causes:**
1. New page (needs time to crawl)
2. Robots.txt blocks it (shouldn't be)
3. noindex meta tag (shouldn't be)
4. Crawl errors

**Fix:**
1. Check `robots.txt` (should be Allow: /)
2. Check page source for noindex (remove if present)
3. Request indexing in Search Console
4. Wait 1-2 weeks

### Issue: Poor Lighthouse Score

**Common problems:**
1. Large unoptimized images
2. Render-blocking CSS/JS
3. Poor color contrast
4. Missing meta tags

**Fix:**
1. Optimize images (compress, reduce size)
2. Preload critical CSS, defer JS
3. Check color contrast (WebAIM tool)
4. Add/verify meta tags and schema
