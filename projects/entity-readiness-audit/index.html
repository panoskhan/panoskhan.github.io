Entity Readiness Audit

A lightweight, browser-based checklist for the public technical signals that help people and search systems understand a website.

Audit a URL

The demo below performs a client-side fetch where the target site permits it. No credentials are requested.

What it checks

Canonical URL
Robots/indexing directives
Open Graph metadata
JSON-LD structured data
sameAs identity links
Sitemap discovery

Why this project exists

Entity visibility depends on consistent, verifiable information. This tool focuses on technical hygiene and transparency rather than promises of rankings, Knowledge Panels, or guaranteed indexing.

Created as an open-source experiment by Panos Khan.
